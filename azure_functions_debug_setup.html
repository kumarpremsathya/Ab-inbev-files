Debug Setup for
Azure Functions in VS Code

Follow this checklist every time you set up debugging in a new Python Azure Functions repo.

Required Files
.vscode/launch.json
.vscode/tasks.json
.vscode/settings.json
local.settings.json
requirements.txt
host.json
1
Install Requirements & debugpy

In the repo root, create a virtual environment and install dependencies:

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install debugpy
⚠️ If Azure Functions sometimes uses the global Python, also run:
py -m pip install debugpy
2
Install Azurite (Local Storage Emulator)

Timer triggers require local storage emulation. Install globally:

npm install -g azurite
ℹ️ Required when local.settings.json contains "AzureWebJobsStorage": "UseDevelopmentStorage=true"
3
.vscode/launch.json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Attach to Python Azure Functions",
      "type": "debugpy",
      "request": "attach",
      "connect": {
        "host": "127.0.0.1",
        "port": 9091
      },
      "preLaunchTask": "func: host start",
      "justMyCode": true
    }
  ]
}
4
.vscode/tasks.json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "azurite: start",
      "type": "shell",
      "command": "azurite.cmd",
      "args": ["--location", "${workspaceFolder}"],
      "isBackground": true,
      "problemMatcher": {
        "owner": "azurite",
        "pattern": { "regexp": "." },
        "background": {
          "activeOnStart": true,
          "beginsPattern": "Azurite",
          "endsPattern": "successfully listening"
        }
      }
    },
    {
      "label": "func: host start",
      "type": "shell",
      "command": "func host start --verbose",
      "isBackground": true,
      "dependsOn": "azurite: start",
      "problemMatcher": "$func-python-watch",
      "options": {
        "env": {
          "languageWorkers__python__defaultExecutablePath":
            "${workspaceFolder}\\.venv\\Scripts\\python.exe",
          "languageWorkers__python__arguments":
            "-m debugpy --listen 127.0.0.1:9091"
        }
      }
    }
  ]
}
5
.vscode/settings.json
{
  "azureFunctions.projectLanguage": "Python",
  "azureFunctions.projectRuntime": "~4",
  "azureFunctions.deploySubpath": ".",
  "python.defaultInterpreterPath": ".venv\\Scripts\\python.exe"
}
6
local.settings.json — Minimum Required Values
{
  "IsEncrypted": false,
  "Values": {
    "FUNCTIONS_WORKER_RUNTIME": "python",
    "AzureWebJobsStorage": "UseDevelopmentStorage=true",
    "languageWorkers__python__defaultExecutablePath":
      "C:\\FULL\\PATH\\TO\\REPO\\.venv\\Scripts\\python.exe",
    "languageWorkers__python__arguments":
      "-m debugpy --listen 127.0.0.1:9091"
  }
}
⚠️ Disabled flags must be set to "false". Example:
"AzureWebJobs.<function_name>.Disabled": "false"
7
Timer Trigger — Easy Debug Setup

Temporarily use a short schedule so breakpoints hit within 10 seconds:

# Hits every 10 seconds — good for debugging
@app.timer_trigger(
    schedule="*/10 * * * * *",
    arg_name="myTimer",
    run_on_startup=False
)
⚠️ Avoid run_on_startup=True while debugging — it can fire before the debugger attaches.
8
Run Debug in VS Code
✅ Use: Run and Debug → Attach to Python Azure Functions → F5
🚫 Do NOT use: Python Debugger: Current File
Common Errors & Fixes
No module named azure.servicebus
Run: .\.venv\Scripts\python.exe -m pip install -r requirements.txt
py exited with code 1
Run both:
.\.venv\Scripts\python.exe -m pip install debugpy

py -m pip install debugpy
ECONNREFUSED 127.0.0.1:9091
debugpy is not listening. Start using the VS Code task — not a manual terminal attach.
127.0.0.1:10000 refused
Azurite is not running. Start it with:
azurite.cmd --location .
Quick Checklist — Every New Repo
  • Create .venv and install requirements.txt
  • Install debugpy in .venv (and globally with py if needed)
  • Install and start Azurite for local storage
  • Add .vscode/launch.json with attach config on port 9091
  • Add .vscode/tasks.json with azurite + func host start tasks
  • Add .vscode/settings.json pointing to .venv
  • Set local.settings.json with correct python path and debugpy args
  • Ensure function is NOT disabled — check Disabled flags are "false"
  • Use short timer schedule */10 * * * * * for easy breakpoint testing
  • Launch via Run & Debug → Attach to Python Azure Functions → F5
