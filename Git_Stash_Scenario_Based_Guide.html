Git Stash - Scenario Based Learning Guide

Think of git stash as a temporary locker.
You save unfinished work into the locker, make your working folder clean, do another task, then bring your work back later.

Scenario 1 - Pull Latest Code

Situation: You modified function_app.py but haven't committed it. Your teammate pushed new code.

Problem: git pull fails because of local changes.

git stash
git pull --rebase
git stash pop

Result: Latest code is downloaded first, then your local work is restored.

Scenario 2 - Switch Branch Immediately

Situation: You're working on feature1. Your manager asks you to fix a production bug.

git stash
git checkout main
# Fix bug
git checkout feature1
git stash pop

Result: Your unfinished work waits safely while you fix the urgent issue.

Scenario 3 - Experimenting

Situation: You changed many files to test an idea but aren't sure if you want to keep it.

git stash
# Try something else
git stash pop

Result: No unnecessary commits for experimental code.

Scenario 4 - Before Rebase

Situation: Git says:

error: cannot pull with rebase:
You have unstaged changes.

Solution:

git stash
git pull --rebase
git stash pop

Scenario 5 - Your Real Example

Your Goal: Push only PolicyExemption.py.

  1. Created PolicyExemption.py.
  2. Committed only that file.
  3. git push failed because remote branch had newer commits.
  4. Ran git stash to temporarily save other uncommitted files.
  5. Ran git pull --rebase origin feature1.
  6. Ran git stash pop to restore local work.
  7. Pushed successfully.
Important: Only PolicyExemption.py was pushed because it was the only file included in the commit. The stash restored other local files afterwards, and those remained local.

Commit vs Stash

CommitStash
Permanent historyTemporary storage
Can be pushedCannot be pushed
Shared with teamLocal to your computer
Completed workUnfinished work

Useful Commands

git stash              # Save changes
git stash list         # List all stashes
git stash pop          # Restore and remove stash
git stash apply        # Restore but keep stash
git stash drop stash@{0}
git stash clear

When Should I Use git stash?

  • ✔ Before pulling latest code.
  • ✔ Before switching branches.
  • ✔ Before rebasing.
  • ✔ When work is unfinished but you don't want to commit.
  • ❌ Don't use it as long-term storage.
