5 ServiceNow Ticket Creation — SnowRequest.create()

ServiceNow/SnowRequest.py

5a. Requestor Lookup (fallback chain)

  1. get_user_details_by_email(data['RequestorEmail'])
  2. If not found → get_user_details_by_oid(data['OID'])
  3. If not found → get_user_details_by_sys_id(data['OID'])

5b. Build Base Payload

request_data = {
    "sysparm_quantity": 1,
    "variables": {
        "u_requester": requestor['sys_id'],
        "u_employee_email": requestor['email'],
        "u_employee_zone": requestor['u_preferred_zone'],
        "zone": "GHQ" if zone in ["BREWDAT","AURORA","TECHOPS","BEES"] else zone,
        "u_on_behalf_of": requestor['sys_id'],
        "u_phone_number": requestor['mobile_phone']
    }
}

5c. Merge Catalog Fields from snow_data()

request_data['short_description'] = data['short_description']
request_data['variables'].update(data['variables'])
// → merges catalog_name, category, zone, tenant, inactive_user_details, inactive_users

5d. Set Default Assignment Group

if request_data.get('assignment_group') is None:
    request_data['assignment_group'] = Constants.SNOW_ASSIGNMENT_GROUP

5e. Create Ticket via ServiceNow API

shared_code/snow_client.py → create_request()

  1. POSTs to /api/sn_sc/servicecatalog/items/.../order_now?assignment_group=...
  2. Gets RITM via get_ritm_status_by_request()
  3. Updates RITM fields (short_description, description, assignment_group) via GlideRecord.update()
  4. Returns serialized RITM + parent Request

5f. Upload Attachment & Set SNOW IDs

self.objsnow.upload_attachment_json(snow_ritm['number'], data)
data['SnowId']             = snow_req['number']       // e.g. REQ0012345
data['SnowItemId']         = snow_ritm['number']      // e.g. RITM0012345
data['SnowStatusCode']     = snow_req['state']
data['SnowItemStatusCode'] = snow_ritm['state']
data['SnowStatus']         = snow_req['stage']
data['SnowItemStatus']     = snow_ritm['stage']

Returns: the data dict now enriched with all ServiceNow identifiers.
