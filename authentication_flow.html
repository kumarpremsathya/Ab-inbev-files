AzSQLServers — Execution Flow Reference

Azure Functions · Python · Azure Resource Graph · Key Vault · Beginner Guide

Overview

Azure Functions timer triggers AzSQLServers daily at 6:00 AM.
It extracts SQL Server and Database metadata from both AzurePublicCloud and AzureChinaCloud using Azure Resource Graph, then saves results to an Excel file (sql_servers_output.xlsx).

Step-by-Step Flow

Step 1

Timer Trigger — function_app.py

Azure Functions fires the timer on schedule. It calls get_sql_servers().

schedule: "0 0 6 * * *"   ← every day at 6:00 AM

def AzSQLServers(myTimer):
    AzSQLServersXtractor().get_sql_servers()
↓
Step 2

get_sql_servers() — AzSQLServers/sql_servers.py

Calls 4 API methods — 2 resource types × 2 clouds. Combines all results and writes to Excel.

servers   = sql_servers_api("AzurePublicCloud")
          + sql_servers_api("AzureChinaCloud")

databases = sql_databases_api("AzurePublicCloud")
          + sql_databases_api("AzureChinaCloud")

→ writes to sql_servers_output.xlsx
↓
Step 3

sql_servers_api(azenvironment) — needs an authenticated client

Requests an Azure Resource Graph client from shared code.

argClient = ResourceGraph().get_resorce_graph("AzurePublicCloud")
# → jumps to shared_code/resourcegraph_client.py
↓
Step 4

get_resorce_graph() — shared_code/resourcegraph_client.py

Picks the Key Vault secret name based on the cloud environment, then fetches SPN credentials.

if azenvironment == "AzurePublicCloud":
    spn_secret_name = "az-public-spn-reader"
elif azenvironment == "AzureChinaCloud":
    spn_secret_name = "az-china-spn-reader"

spn_token = SpnToken().get_spn_token(spn_secret_name)
# → jumps to shared_code/spn_token.py
↓
Step 5

get_spn_token(secret_name) — shared_code/spn_token.py

Fetches the secret from Key Vault and converts the raw JSON string into a Python dict.

secrets_obj = AkvSecrets(os.environ["KEYVAULT_URI"], "az-public-spn-reader")
spn_token   = secrets_obj.get_tokens()       # returns SecretBundle object
spn_token   = json.loads(spn_token.value)    # JSON string → Python dict
return spn_token
# → jumps to shared_code/akv_secrets.py for get_tokens()
KEYVAULT_URI comes from local.settings.json: https://puppetapi-secrets.vault.azure.net/
↓
Step 6

get_tokens() — shared_code/akv_secrets.py

Authenticates to Azure Key Vault using DefaultAzureCredential and retrieves the secret.

credential = DefaultAzureCredential()
# Reads AZURE_CLIENT_ID, AZURE_CLIENT_SECRET, AZURE_TENANT_ID
# from local.settings.json automatically

client = SecretClient(vault_url=self.uri, credential=credential)
retrieved_secret = client.get_secret("az-public-spn-reader")
return retrieved_secret   # SecretBundle object
Key Vault stores the secret as a raw JSON string:
{"client_id": "abc123", "secret": "xyz789", "tenant": "tenant-id"}
Key Vault always returns a string. It is json.loads() in Step 5 that converts it to a dict.
↓
Step 7

Back in get_resorce_graph() — builds authenticated client

Uses the dict from Step 5 to build Azure credentials and return a ready-to-use Resource Graph client.

credentials = ClientSecretCredential(
    client_id     = spn_token["client_id"],
    client_secret = spn_token["secret"],
    tenant_id     = spn_token["tenant"]
)
res_graph_client = ResourceGraphClient(credentials)
return res_graph_client   # ← authenticated, ready to query Azure
↓
Step 8

Back in sql_servers_api() — queries Azure Resource Graph

Sends a KQL query to Azure. Handles pagination — fetches all pages if results exceed 1000.

result   = argClient.resources(argQuery)   # first page (up to 1000)
all_data = result.get("data", [])

while result.get("skip_token"):            # more pages exist?
    result    = argClient.resources(next_page_query)
    all_data += result.get("data", [])

return all_data   # complete list of SQL server records
↓
Step 9

Back in get_sql_servers() — saves output to Excel

pd.DataFrame(servers).to_excel(writer,   sheet_name="SQLServers")
pd.DataFrame(databases).to_excel(writer, sheet_name="SQLDatabases")
# → sql_servers_output.xlsx

Full Call Chain Diagram

Timer Trigger
 └── function_app.py → AzSQLServersXtractor().get_sql_servers()
      └── sql_servers.py → sql_servers_api("AzurePublicCloud")
            └── resourcegraph_client.py → get_resorce_graph()
                  └── spn_token.py → get_spn_token("az-public-spn-reader")
                        └── akv_secrets.py → get_tokens()
                              └── Azure Key Vault
                              ← SecretBundle (.value = raw JSON string)
                        ← json.loads() → dict {client_id, secret, tenant}
                  ← ClientSecretCredential → ResourceGraphClient returned
            ← argClient.resources(KQL query) → list of SQL server records
      └── (same repeated for AzureChinaCloud, sql_databases_api ×2)
 └── all results merged → sql_servers_output.xlsx

Key Concepts

ConceptExplanation
DefaultAzureCredential Reads AZURE_CLIENT_ID, AZURE_CLIENT_SECRET, AZURE_TENANT_ID from local.settings.json to authenticate to Key Vault. This is the root credential that unlocks everything.
Azure Key Vault Stores SPN credentials as a JSON string — credentials are never hardcoded in the source code.
json.loads() Converts the Key Vault string response into a Python dict so individual fields can be accessed by key.
ClientSecretCredential Uses the SPN credentials fetched from Key Vault to authenticate to Azure Resource Graph.
Azure Resource Graph A query service that searches Azure resources (SQL servers, databases, etc.) across all subscriptions at once using KQL (Kusto Query Language).
Pagination (skip_token) Resource Graph returns a maximum of 1000 records per call. The while loop keeps fetching next pages until all records are retrieved.
local.settings.json Local config file — equivalent of App Settings when deployed to Azure. Holds all environment variables used at runtime.

Environment Variables (from local.settings.json)

VariablePurpose
AZURE_TENANT_IDTenant ID — used by DefaultAzureCredential to authenticate to Key Vault
AZURE_CLIENT_IDClient ID — used by DefaultAzureCredential to authenticate to Key Vault
AZURE_CLIENT_SECRETClient Secret — used by DefaultAzureCredential to authenticate to Key Vault
KEYVAULT_URIURL of the Azure Key Vault instance where SPN secrets are stored
