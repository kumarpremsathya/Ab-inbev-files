API Clients — Project Reference

Which API client is used in each file · Endpoint · Purpose · SDK

Quick Summary

Resource data (SQL, RBAC, MgmtGroups) → ResourceGraph() → management.azure.com
Azure AD data (Users, Groups, SPNs) → GraphClient() → graph.microsoft.com
Subscription listing → SubscriptionsClient() → management.azure.com
Email notifications → ClientSecretAuth() → SMTP service
3rd party APIs (BeyondTrust, Saviynt) → SpnToken() → custom HTTP calls

1. ResourceGraph()

ResourceGraph()

Azure Resource Graph API

Queries resources across all subscriptions at once using KQL — faster than calling per-subscription APIs

POST management.azure.com/providers/Microsoft.ResourceGraph/resources
FileWhat It Queries
AzSQLServers/sql_servers.pySQL Servers & Databases (name, location, admin, TLS, AAD config, edition, size)
AzRBAC/rbac.pyRBAC role assignments across all subscriptions
AzRbacRoles/rbacRoles.pyRBAC role definitions (built-in & custom)
AzManagementGroups/management_groups.pyAzure Management Group hierarchy

2. GraphClient()

GraphClient()

Microsoft Graph API

Queries Azure AD objects — users, groups, SPNs, sign-in logs, auth methods via Microsoft Graph SDK

graph.microsoft.com/v1.0 or /beta
FileWhat It Queries
AzUsers/users.pyAzure AD Users (profile, licenses, MFA status)
AzGroups/groups.pyAzure AD Groups and their members
AzSPNs/spns.pyService Principals (app registrations, credentials, owners)
AzEntraRBAC/entra_rbac.pyEntra (Azure AD) RBAC role assignments
AzIdentityGovernance/groups_zero_members.pyGroups with zero members
AzIdentityGovernance/spn_signin_logs.pyService Principal sign-in logs
AzIdentityGovernance/users_auth_methods.pyUser authentication methods (MFA, passwordless)

3. SubscriptionsClient()

SubscriptionsClient()

Azure Subscriptions API

Lists all Azure subscriptions — used to iterate over each subscription individually

GET management.azure.com/subscriptions
FileWhat It Does
AzPIM/pim.pyLists subscriptions before fetching PIM schedule requests per subscription
AzRbacMetrics/rbacMetrics.pyLists subscriptions before computing RBAC metrics per subscription

5. SpnToken() — Direct Token (3rd Party APIs)

SpnToken()

Custom / 3rd Party API Authentication

Fetches raw SPN credentials from Key Vault for use in direct HTTP calls — no Azure SDK client involved

Custom REST endpoints
FileAPI CalledPurpose
BeyondTrustAccounts/BeyondTrustAccounts.py BeyondTrust PAM REST API Fetches privileged account data from BeyondTrust Password Safe
SaviyntMicsData/saviynt_mics.py Saviynt IGA REST API Fetches MICS (Managed Identity & Cloud Security) data from Saviynt

How They All Connect to Shared Code

── All clients ultimately go through shared_code ──

ResourceGraph() → shared_code/resourcegraph_client.py → SpnToken() → AkvSecrets()
GraphClient() → shared_code/graphservice_client.py → SpnToken() → AkvSecrets()
SubscriptionsClient() → shared_code/subscriptions_client.py → SpnToken() → AkvSecrets()
ClientSecretAuth() → shared_code/client_secret_auth.py → SpnToken() → AkvSecrets()
SpnToken() → shared_code/spn_token.py → AkvSecrets()

── Every single client fetches credentials from Key Vault at runtime ──
